# Community Event Readiness

Use the existing operating record as the source of truth. Pull together event details, venue replies, capacity and access rules, registrations, owners, program and fallback, budget constraints, and the user's decisions. Keep historical snapshots dated. After a date, venue, time or benefit changes, check the active operating record, registration page, volunteer brief, and any in-scope public copy for stale details. Update only the destinations the user authorized.

## Prepare the room and program

- Check current venue records for usable capacity for the intended layout, permitted access hours, routes, and any staffing conditions. Prepare unresolved venue questions for the owner or send them only when authorized. Keep the timestamped RSVP snapshot, planning turnout range, confirmed capacity, and day-of count as distinct figures. Base door and seating plans on the room that can actually be used.
- Walk the arrival route from the entrance through check-in to the room. Identify accessible access, bottlenecks, staffed posts, wayfinding, check-in and walk-in handling, and teardown requirements. Use a diagram to plan placement if useful. Confirm dimensions and flow on site.
- Set AV acceptance criteria before shopping or allocating equipment. Include room lighting and throw, legibility from the back, speaker audio, playback, screen sharing, network and setup time. Compare a bounded shortlist within the approved budget. Test the actual room, sources and signal path and give the operator a simple fallback such as offline video or a no-visual format. Record test results and distinguish digital layout checks from on-site checks.
- Build the run of show by segment, speaker, duration, cue, transition, lead and fallback. Track interest, accepted invites, approved slots and tested assets separately. When there are lightning talks and visual demos, give each its own submission and rehearsal requirements. Make the host’s instructions clear enough to run without the organizer doing every job.
- Confirm sponsor terms before publishing benefits, prizes or eligibility. Verify supplier arrival, receiving and service owners and needs such as dietary labeling or storage with their source. Put unresolved requirements and decisions beside the segment they affect.

## Hand off to the day-of team

Use a compact table of roles with acceptance status, main owner, backup, location, arrival time and the next handoff. Separate volunteer availability from accepted shifts. Cover check-in, venue or lobby, stage and AV, hospitality, and closeout as applicable. Flag gaps in continuous coverage and assign a realistic fallback if the host is already on stage.

Give the closeout lead a simple way to collect the final registration snapshot, deduplicated door counts including walk-ins and staff categories, delivered segments and deviations, a few feedback observations, equipment custody, and receipts. Obtain permissions for any planned recording or public use. Use existing forms and trackers where appropriate.

Return the fact sheet, a runnable handoff, and the few readiness decisions that still need an owner or evidence. Label the readiness of each critical item by source and date so another host can tell what has been tested, what has been accepted, and what is still provisional.
